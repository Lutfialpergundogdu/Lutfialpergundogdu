## English

### Focus

- Renewable resource assessment across Türkiye: **solar, wind and wave energy**
- Hourly and multi-year energy simulation with **SAM / PySAM**
- Statistical validation, machine-learning surrogates and uncertainty analysis
- Reproducible desktop tools, reports and decision-support workflows

### Selected work

#### 🌊 Wave Energy App · private research project

A bilingual desktop application for wave-energy assessment in Turkish seas. It combines Copernicus Marine and buoy data with SAM 2026.7.3 / PySAM, evaluates RM3, RM5 and RM6 reference devices, compares sites and years, benchmarks ML surrogates and regional statistics, and produces sourced DOCX/PDF reports.

`Python` `PySAM` `SAM` `scikit-learn` `statsmodels` `pandas` `Plotly`

#### 🌬️ Offshore Atlas · private research workbench

A traceable offshore-wind workflow for native resource grids, quality control, NREL PySAM simulations, CF/AEP/LCOE reporting and open-data validation. It also includes an experimental FINO1 LiDAR comparison and ML validation pipeline.

`Python` `FastAPI` `PySAM` `xarray` `scikit-learn`

#### ☀️ [Sunergy Atlas](https://github.com/Lutfialpergundogdu/Gunes_enerjisi_potansiyeli)

A desktop solar-energy analysis tool combining NASA POWER data, PVWatts V8 through PySAM, Rust-based data processing, statistical analysis and forecasting. It exports reproducible CSV, visual and source-aware HTML/JSON reports.

`Python` `Rust` `PySAM` `NASA POWER` `SQLite`

#### ⚡ EnergyStudio · private product prototype

A Türkiye-focused solar and wind pre-feasibility platform with map-based site selection, screening gates, multi-year NLR-PySAM simulation, P50–P99 production ranges, financial indicators, sensitivity analysis and source-attributed reports.

`Python` `Rust` `Tauri` `NLR-PySAM` `GIS`
