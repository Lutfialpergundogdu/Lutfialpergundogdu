## What I work on

- **Renewable resource assessment:** solar, onshore/offshore wind and wave energy across Türkiye
- **Scientific computing:** hourly and multi-year energy simulation with SAM / PySAM
- **Data & machine learning:** reanalysis and satellite data, statistical validation, surrogate models and uncertainty analysis
- **Decision-support software:** desktop and browser tools with traceable assumptions, sources and exportable reports

## Selected projects

### 🌊 Wave Energy App · private research project

A bilingual desktop decision-support application for wave-energy assessment in Turkish seas. It combines Copernicus Marine and buoy data with SAM 2026.7.3 / PySAM, evaluates RM3, RM5 and RM6 reference devices, compares sites and years, benchmarks ML surrogates and regional statistics, and produces sourced DOCX/PDF reports.

`Python` `PySAM` `SAM` `scikit-learn` `statsmodels` `pandas` `PyWebView` `Plotly`

### 🌬️ Offshore Atlas · private research workbench

A traceable offshore-wind analysis workflow for native resource grids, quality control, NREL PySAM simulations, CF/AEP/LCOE reporting and open-data validation. Includes an experimental FINO1 LiDAR comparison and ML validation pipeline.

`Python` `FastAPI` `PySAM` `xarray` `scikit-learn` `statistics`

### ☀️ [Sunergy Atlas](https://github.com/Lutfialpergundogdu/Gunes_enerjisi_potansiyeli)

A desktop solar-energy analysis tool that combines NASA POWER data, PVWatts V8 through PySAM, Rust-based data processing, statistical analysis and forecasting. It exports reproducible CSV, visual and source-aware HTML/JSON reports.

`Python` `Rust` `PySAM` `NASA POWER` `SQLite` `scikit-learn`

### ⚡ EnergyStudio · private product prototype

A Türkiye-focused solar and wind pre-feasibility platform: map-based site selection, low-cost screening gates, multi-year NLR-PySAM simulation, P50–P99 production ranges, financial indicators, sensitivity analysis and source-attributed reports.

`Python` `Rust` `Tauri` `NLR-PySAM` `JavaScript` `GIS`

### 🎵 [PlayBridge](https://github.com/Lutfialpergundogdu/playbridge)

A TypeScript web application for managing and synchronising playlists across Spotify, YouTube Music and Apple Music, with conservative track matching, OAuth integrations and explicit handling of unmatched tracks.

`TypeScript` `React` `OAuth` `Spotify API` `YouTube Data API`
